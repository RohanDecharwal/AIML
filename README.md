# 🚀 Projects

| Assignment | Project | Description |
|------------|---------|-------------|
| 1 | Medical Insurance Cost Prediction | Multiple Linear Regression model to predict medical insurance charges. |
| 2 | Customer Churn Prediction | Logistic Regression model to predict customer churn. |
| 3 | Salary Prediction | Polynomial Regression model for salary prediction based on position level. |
| 4 | Breast Cancer Classification | K-Nearest Neighbors (KNN) model to classify breast tumors as benign or malignant. |
| 5 | Employee Attrition Prediction | Comparison of Decision Tree and Random Forest classifiers for employee attrition prediction. |
| 6 | Weather Condition Classification | Support Vector Machine (SVM) model using Open-Meteo API weather data. |
| 7 | Customer Segmentation | K-Means Clustering and PCA for customer segmentation and visualization. |
| 8 | Handwritten Digit Recognition | Artificial Neural Network (ANN) for handwritten digit classification using the MNIST dataset. |

# 💻 Getting Started

Clone the repository:

```bash
git clone https://github.com/RohanDecharwal/AIML.git
```

Move into the repository:

```bash
cd AIML
```

Navigate to any assignment folder:

```bash
cd Adult_Census_Income_Classification
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Open the notebook in Jupyter Notebook, Google Colab, or VS Code and run all cells.
